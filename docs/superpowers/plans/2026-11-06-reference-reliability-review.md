# 第三批能力吸收：恢复、审阅与历史

## 边界

保留已有未提交改动，不添加依赖。Core 只定义通用变更证据；Coding 工具在锁内记录成功写入的前后快照；host services 管 MCP、会话索引和分轮审阅；TUI/Web 仅消费投影。终端预算、durable Run 预算、权限确认与重试身份不变。

## 实施与验收

1. MCP：以单服务连接槽承接现有连接器；失败服务不阻止其他服务，显示 connected/failed/needs-auth/disabled；`/mcp reconnect <name>` 仅重连目标，重连失败保留旧的有效连接，关闭时取消并等待在途连接。保留严格底层连接器行为及兼容性测试。
2. 按轮审阅：成功 edit/write 发出有界前后证据，按实际提交轮次持久记录；`/changes` 展示本轮/历史工具变更，独立于 `/diff` 的全工作区变化。Shell/外部变更明确为未归因，不从当前 Git 状态猜测。截断与缺少快照须提示。
3. Web Markdown：复用已有 marked 依赖提供浏览器解析，使用受控 DOM 节点渲染标题、列表、表格、代码与链接；禁用原始 HTML、脚本 URL、图片自动请求。保留复制原文和流式刷新体验。
4. 历史检索：`/history <query>` 检索工作区下跨会话输入，提供来源与预览，选择仅加入空草稿，不自动发送。检索中间输入，不将输入历史等同于全部回答全文索引。
5. 会话加载：默认只读取最近一页；元数据按文件版本缓存，变化后刷新；完整 transcript 改为显式按需预览。查询仍覆盖更早会话。
6. 压缩可视化：从已有 compact_boundary 记录提取时间、前后 token 数及摘要；`/compactions` 按需展开；压缩进行中和完成后都有真实事件提示，不引入额外摘要调用。

## 验证

先增加边界回归，再依次接入。覆盖 MCP 失败隔离/重连/关闭，写入证据成功与失败路径，历史中间输入命中、缓存失效、压缩元数据、Markdown 注入与链接协议。最后跑相关测试、typecheck、全量测试、build 和 Web 浏览器验证。未验证的真实服务/平台限制在最终报告说明。

## 交付状态

六项已实现。入口：`/mcp reconnect <server>`、`/changes [turn]`、`/history [query]`、`/session-preview <id>`、`/compactions`，以及 Web 回答 Markdown。分轮证据由 Core 原生 tool-result 保存，估算/模型请求/压缩输入剥离该本地元数据；现有行 diff 算法下沉到共享 git service，UI 保留兼容导出。

范围：独立 MCP 连接槽用于交互宿主，底层严格连接器及后台策略保留；已有 in-process transport 无法复用重连，需要宿主提供新 transport。会话索引是有界内存缓存，查询仍需检查文件元数据；完整审计上限 32 MiB。历史复用只包含文本，Shell/外部变更不归因。Web Markdown 不自动加载图片，超大表格有明确截断。

验收：最终全量 **1295 pass / 3 平台 skip / 0 fail**；最后界面摘要和历史复用相关两文件 **36 pass**；类型检查、构建、diff 空白检查通过。Playwright Chromium 已验证桌面与 390px 移动视口的表格、列表、代码块、原始 HTML 不执行、草稿保护及既有工具卡交互。首轮验证暴露的冷启动复合测试超时已拆成逐命令测试；文件监听回归改为在原五秒总期限内等待真实事件，断言保留。未更新本地安装、重启服务或提交远程。
