# 第二批参考交互吸收方案

目标：保持终端与 durable Run 的预算边界，复用现有 host services。先交付 TUI，再按用户后续授权扩展 Web（见下方 Web 扩展）。

## 实施顺序及验收

1. 工作区内容检索：workspace service 使用有界、可取消的 rg；TUI `/search <text>` 展示文件、行号与上下文，选择后把引用加入草稿，不自动发模型。只搜索当前工作区，遵循 ignore；超时/截断/失败须明确。
2. 子任务进度：沿既有工具进度事件传递真实子任务阶段和最近工具，展示耗时与运行状态；复用任务工作台，不新建调度器、不改预算。
3. 消息操作：复用 transcript 选择与复制，支持遍历所有消息；选中用户消息可放回草稿编辑，选中工具可复制其输入。编辑仅复用，不隐式回滚或发送。
4. 返回摘要：host policy 在终端失焦期间累计工具完成/失败；返回时展示一次本地摘要与待处理事项。无额外模型请求，限制内存，不持久化敏感输出。

## 边界与验证

保留全部既有未提交改动，不复制参考产品的遥测/账号系统，不添加依赖。服务与纯函数先覆盖边界回归测试；集成后运行相关 TUI 测试、typecheck、build。缺少真实终端验证必须明确披露。

各项按可独立审阅的服务、事件、TUI 接入分离；当前文档为实施与验收清单，完成状态以测试及最终报告为准。

## 本轮交付及验证

四项已接入现有入口：`/search` 管理面板、工具进度事件、可配置消息快捷键、终端焦点事件。消息复用保存当前会话输入快照，恢复文本粘贴和图片引用；旧历史缺少快照时不冒充完整恢复。

本轮范围：搜索使用显式命令而非输入时自动扫描；搜索服务支持取消，交互命令以三秒超时保证有界。子任务进度用于前台 agent 工具，后台仍在任务工作台查看。返回摘要汇总失焦期间前台工具完成/失败及返回时待处理数量，不生成模型摘要，也不宣称覆盖所有后台文件变更。

验证：全量测试 1277 pass / 3 平台 skip / 0 fail（随后输入快照修复另有相关六文件 53 pass）；TypeScript 类型检查通过。构建及最终检查见本次交付报告。没有更新本地安装、重启后台或推送远程。

## Web 扩展（用户已授权）

复用 workspace 内容搜索，增加同源授权、固定工作区、可取消的检索接口及结果对话框。Web 仅提交 query，不能选择任意目录。聊天投影保留有界工具阶段/最近工具/耗时，浏览器按工具单独展开。每条消息增加复制，用户消息增加复用到空草稿，不回滚历史、不自动发送；未知结果的重试身份与已有授权流程保持。

页面隐藏期间依据已选对话的工具/消息标识计算本地返回摘要，不额外请求模型；切换会话清除基线，避免重复播报。验证包括 host 固定工作区检索测试、HTTP 授权测试、Web 聊天回归、脚本语法和浏览器交互验证。

Web 验证结果：全量 1281 pass / 3 平台 skip / 0 fail；最后的搜索取消回归与聊天投影测试另跑 12 pass。类型检查、浏览器脚本构建和整体构建通过。Playwright Chromium 在 1440px 桌面与 390px 移动视口通过搜索上下文、引用仅入草稿、复制、草稿保护、真实进度投影、展开状态保留、Escape、文本注入防护；返回摘要以模拟 visibilitychange 验证。未更新本地安装、重启服务或提交远程。
