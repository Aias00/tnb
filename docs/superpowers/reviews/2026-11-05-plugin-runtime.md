# 外部插件工具运行时实现审阅

本轮落实插件规范中外部工具的网络执行和资源归属路径，补齐三个实际缺口：HTTP 原先只检查网络声明不是 none；oneshot/HTTP 完整读取后才截断，stdio 还可无限累积未完成帧；停止仅处理 stdio 进程，没有等待 HTTP/oneshot 调用。使用合同和限额见[外部工具指南](../../guides/plugin-tool-runtime.md)。

## 实现决策

网络准入使用纯函数，发现清单和调用时复用。loopback 仅接受数字回环及固定连接地址的 localhost，所有重定向拒绝，不对带业务效果的 POST 自动转发。HTTP 外部工具不允许 command args 或 URL 凭据，外部 in_process 工具在发现时拒绝，不接收随后被忽略的传输选项。

项目固定 Bun 1.3.14。该版本的 [node HTTP 实现](https://raw.githubusercontent.com/oven-sh/bun/bun-v1.3.14/src/js/node/_http_client.ts)最终使用内部 fetch；故障夹具复现了环境代理影响，以及裸 `undici` 模块缺少真实 Client 清理方法的兼容差异。因此固定依赖 `undici@7.30.2`，通过 `undici/index.js` 引入实际包，每次调用独立 Client 并等待 destroy。独立进程夹具设置错误代理，编译产物夹具在没有项目依赖目录的工作目录运行，均验证实际连接直达本机目标。依赖许可证随 dist/licenses 发布。

字节预算在解码和解析前实施，同时限制完整结果、stderr、单帧和 stdio 生命周期累计流量。stdout 和 stderr 同时排空；异常路径取消读取并终止直接子进程。若直接子进程忽略正常终止，升级 SIGKILL 并等待 child.exited，不把仅发出 kill 当作退出证明。

调用在传输启动前加入 owner 集合，JSON 参数快照、期限和调用取消均归属于该项。stop 先退休代际，close 先关闭准入，再取消和等待资源；重复关闭共享 Promise。等待同一代际排空的激活不会提前复用旧进程。stdio 的取消会结束共享进程，其他 pending 请求一并失败，没有隐式重试。eager 部分启动失败会清理整包资源，常驻进程和在途调用分别有数量上限。

## 验收场景

| 路径 | 观察到的结果 |
| --- | --- |
| loopback 外部主机、DNS 别名、任意监听地址、映射 IPv6 | 发现或派发前拒绝；不依赖一次 DNS 结果宣称受限 |
| localhost、重定向、错误代理环境和编译产物 | 固定本机连接、零重定向目标请求、零代理请求 |
| 无 Content-Length 的持续 HTTP 输出 | 达读取上限失败并关闭连接，不返回部分成功 |
| 持续 stdout/stderr、未完成超长帧、累计通知、超大结果 | 对应字节预算触发，进程或调用停止 |
| 大量合法 stderr 与小 stdout 同时输出 | 两条管道并发排空，保留完整成功结果 |
| 无响应 HTTP/stdio、忽略 SIGTERM 的子进程 | 期限取消且不重试，直接子进程退出得到确认 |
| 多路 stdio 乱序响应、拆分 Unicode | 按 id 返回完整且正确的各请求结果 |
| stdio 一个请求取消、另一个仍在途 | 两项均失败，下一次独立请求才重建进程 |
| 超并发、超输入、超常驻进程数 | 新效果前拒绝，部分 eager 激活回滚 |
| 慢包及健康包并发、调用对象随后变更 | 健康包独立执行，发送参数保持原快照；停止慢包不影响它 |
| 重复 stop/close | 共享清理完成结果，不提前报告停止 |
| 激活等待旧资源排空时出现更新的 stop | 旧激活拒绝，最新停止意图保持生效 |
| 服务返回压缩正文 | 请求 identity，拒绝压缩响应，不以压缩前大小绕过输出预算 |
| HTTP/stdio 回复缺少 result/error | 明确失败，stdio 在删除 pending 之前检查，避免请求悬挂至超时或返回空成功 |

## 保证范围

本轮部分落实 AUTH-05、LIFE-01 至 LIFE-05 及 PKG-01，范围限于外部插件工具。没有为任意可信进程内代码新增隔离进程，未提供后代进程树的强制回收、最小环境、凭据引用或配置/状态协议。既有 MCP/Channel/业务 Adapter 的执行不自动采用这些限额。超时和取消不证明远端效果消失；原任务绑定、journal 的重放安全判断与 unknown 核对机制不变。

本轮由实现者审阅，没有委派其他 Agent。验证使用临时文件、离线夹具、本机 HTTP 和真实子进程，不调用付费模型或外部业务服务。Windows CI 将新增运行时故障和编译夹具；macOS/Linux 继续完整测试。

## 本地验证

macOS 在 `TNB_REQUIRE_NATIVE_SANDBOX=1` 下通过全量 1088 项测试，2 项其他平台专属测试跳过，0 失败，覆盖 161 个测试文件。新增运行时验收 18 项，包含真实子进程、代理干预、编译产物及畸形响应。类型检查、完整构建、19 处本地文档链接及 staged diff 检查通过。
