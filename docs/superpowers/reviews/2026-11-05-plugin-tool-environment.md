# 外部插件工具环境合同审阅

审阅对象为[规格](../specs/2026-11-05-plugin-tool-environment.md)及[操作指南](../../guides/plugin-tool-environment.md)。原代码把宿主整份环境传给工具，本轮改为有限运行变量、私有目录与宿主显式引用。

## 实现审阅

引用固定包指纹和工具 ID，宿主环境保存为独立私有快照，不能通过 JSON 序列化 runtime 意外导出。配置仅来自用户设置；项目信任及 --settings 不能提升该权限。工具 manifest 中不支持的字段明确拒绝，不能声明 env 来授权自己。

配置更新在任何异步排空前拒绝新调用，旧调用按原 owner 取消并等待。工具目录持有绑定身份；更新身份不转移到已批准的旧句柄。刷新在发现资源和 ConfigChange Hook 前落实宿主授权变化，避免插件 veto 掩盖撤权。等价排序不触发重启。

引入异步私有目录准备后重新核对进程槽、调用取消和停止状态，避免多个 stdio 调用各创建一份进程。回归发现旧激活请求可能在新增 await 后捕获过新的停止 epoch；现已在第一处 await 前拍摄意图，原“停止优先”测试继续通过。新增可控准备屏障验证：用户在准备期间取消后不会启动 stdio 进程；过期激活也不能替较新的激活清理资源。

路径和标准配置目录归临时 owner 管理，正常排空后清理；数量有限，清理失败阻止新准入。没有把目录数量上限表述为磁盘配额，也没有把正常 close 扩展为 SIGKILL 后自动回收。

输出处理只对已获批值做精确替换，错误不保留携带原始值的 cause；不将编码/拆分、插件私有日志或网络泄漏当作已解决。最小环境不是 OS 隔离，进程内扩展和独立 MCP/Channel 各保持自身合同。

## 验收

专项包括真实 oneshot/stdio 进程、精确包/工具授权、加载器与密钥隔离、HOME 清理、并发 stdio、撤权与旧句柄、源环境快照、等价顺序、数量上限、项目/overlay 越权和 HTTP 拒绝。额外通过编译的独立工具、真实安装/信任与 CLI/SDK、本机脚本模型验证配置确实进入执行路径，并且模型收到的工具结果中没有凭据正文。

新增 15 项环境集成测试，连同原运行合同、参数、准入、设置和发现专项通过 74 项、378 次断言。macOS 设置 `TNB_REQUIRE_NATIVE_SANDBOX=1` 的最终完整回归通过 1187 项、跳过 3 项、0 失败，共 170 个文件、4945 次断言。类型检查、构建、68 处本地文档链接及 `git diff --check` 通过。编译版宿主与编译版工具通过两次本机模型请求验证了授权传入、无关密钥隔离与模型结果替换。

一轮完整回归中，既有 ConfigChange 文件监听测试未在其等待窗口内产生日志；该文件单独复测 8 项通过，最终完整回归也通过，未通过跳过或放宽断言处理。没有确认该次事件缺失的根因。Windows 工作流加入同一组环境专项，远端结果以对应提交的工作流为准。
